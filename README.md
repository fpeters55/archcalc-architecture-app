## What Is ArchCalc?

ArchCalc brings architecture-related utilities together in a simple web interface. The project is packaged as an HTML application, so it can be opened from the published web build or served from a local copy of the repository.

It is intended for users who want architecture-focused tools without setting up a conventional desktop program. Since the application runs in a modern browser, it can be accessed through the web while remaining easy to download, examine, and run locally.
